# Desktop File Catalog v1.0.0 / 桌面文件管家 v1.0.0

## English

Download `DesktopFileCatalog-v1.0.0-win-x64.zip`, extract it to a writable folder, and double-click `桌面文件管家.exe`. This is a self-contained Windows x64 build; no .NET installation is needed.

The app scans a chosen folder locally, supports file-name/path search and exact-content duplicate review, compares complete scans, and exports either a full CSV or a smaller HTML share summary. It does not delete, move, rename, or upload your files. The ZIP contains no scan history or personal file catalog.

Check `SHA256SUMS.txt` before running the download. On Windows PowerShell, run `Get-FileHash .\DesktopFileCatalog-v1.0.0-win-x64.zip -Algorithm SHA256` and compare its hash with the ZIP line in that file. This community build is not code-signed.

## 简体中文

下载 `DesktopFileCatalog-v1.0.0-win-x64.zip`，解压到可写入的文件夹，再双击 `桌面文件管家.exe`。这是 Windows x64 自包含版本，不必另装 .NET。

程序在本机扫描指定文件夹，可按文件名和路径搜索、检查内容相同的文件、比较完整扫描的变化，并导出完整 CSV 或较简洁的 HTML 分享摘要。程序不会删除、移动、重命名或上传个人文件。ZIP 中不包含任何扫描历史或个人文件目录。

运行前可用 PowerShell 执行 `Get-FileHash .\DesktopFileCatalog-v1.0.0-win-x64.zip -Algorithm SHA256`，并与 `SHA256SUMS.txt` 中的 ZIP 校验值比较。此社区版本没有代码签名。
