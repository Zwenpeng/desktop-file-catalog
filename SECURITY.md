# Security / 安全

## English

Do not post private file paths, personal documents, credentials, or unredacted scan exports in a public issue. To report a security concern, open a GitHub issue containing only a minimal, synthetic reproduction and ask how to share sensitive details privately. Do not run EXE files from unofficial mirrors; compare downloads with the checksum attached to the GitHub release.

The app has no delete, move, or rename action. Its context menu can open a selected file with Windows, including an executable, so review a file before opening it. A scan can encounter access-denied paths; when that happens, the app does not update the history baseline.

## 简体中文

不要在公开 Issue 中上传私人路径、个人文档、密钥或未经处理的扫描导出文件。报告安全问题时，请先用虚构的最小复现信息创建 Issue，再讨论如何私下提供敏感细节。只从本项目 GitHub Release 下载，并核对校验值。

程序没有删除、移动或重命名操作。右键菜单可让 Windows 打开选中的文件，包括可执行文件；打开前请确认文件来源。扫描遇到无权读取的路径时，程序不会更新历史基线。
